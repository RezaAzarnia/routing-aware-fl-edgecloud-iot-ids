# Optional Windows helper scripts

These batch files are optional wrappers for Windows users. They are not required for reproducing the experiments; the main and platform-independent execution path is through the Python commands documented in the root `README.md`.

Run these files from anywhere. Each script first changes the working directory to the repository root before launching the corresponding Python command.

## Main helper scripts

- `install_requirements.bat`
- `check_ciciot2023_dataset.bat`
- `prepare_ciciot2023_paper.bat`
- `run_main_ciciot2023_eps10_eps20_5seeds.bat`
- `run_ciciot2023_baselines_5seeds.bat`
- `run_ciciot2023_ablations_3seeds.bat`
- `run_ciciot2023_key_sweeps_3seeds.bat`

## Optional development helpers

- `optional_run_ciciot2023_preflight.bat`
- `optional_run_ciciot2023_pilot.bat`
- `optional_run_clip_screen_1seed.bat`
