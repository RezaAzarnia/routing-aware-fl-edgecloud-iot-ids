# Final-test script changelog (Phase 9C): new versioned pathway `scripts/final_test/`

Historical `scripts/phase6c/final_test_evaluate.py` is **unchanged** (it is part of the Phase 6C code fingerprint and of the frozen tag). The new pathway is separate; nothing in it opens, hashes, samples or evaluates a locked test file during development or testing (verified by the guard, see below).

| # | Requirement | Implementation |
|---|---|---|
| 1 | Preserve Phase 6C implementation/results | old script, `results_phase6c/`, manifests untouched; Phase 6C and 7b verified 240/240 and 40/40 after the work |
| 2 | Use validated Phase 7b metric logic | `metrics_at` calls the repaired `src.metrics.binary_classification_metrics` (single rule `score >= threshold`, raw-score AUC); evaluation tree is fingerprinted, and a synthetic test recomputes TP/FP/AUC independently |
| 3 | No change to training algorithms | `src/` not modified in Phase 9C |
| 4 | Never refit preprocessing on test data | AST test: no `fit`/`fit_transform`/`train_test_split`/`select_decision_threshold` call anywhere in `final_test_v2.py`; a monkeypatch test makes `ColumnTransformer.fit*` raise during `prepare_test_matrix` and `evaluate_one` |
| 5 | Reuse the exact training-fitted preprocessor | `preprocessor.joblib` of each run is loaded; its SHA-256 is frozen in the manifest (it was **not** part of `COMPLETE.json`) and re-checked before use |
| 6 | If unavailable, demonstrate equivalence | not needed (all present); additionally `preproc-equiv` refits from **training data only** (`load_dataset(load_test=False)`) and compares every fitted parameter (feature names, imputer statistics, scaler mean/scale, one-hot categories): **12/12 (dataset, seed) pairs identical** (UNSW seeds 12-21, CIC seeds 12 and 16); evidence `evidence/preprocessor_equivalence.json` |
| 7 | Verify feature order, dimensions, encoders, scalers, model compatibility | `readiness`: output dimension equals `encoded_feature_dimension`; `state_dict` loads with `strict=True` and `weights_only=True` for all 560 checkpoints; `prepare_test_matrix` aborts on any missing/extra column and orders by `feature_names_in_`. Note: UNSW one-hot dimension is 192-194 depending on the seed's training split, hence per-run preprocessors |
| 8 | Only frozen checkpoints and predetermined thresholds | manifest freezes checkpoint hashes, `best_round`, and thresholds read from the run records (calibration partition); `evaluate_one` asserts hashes before loading and uses only these thresholds; a test asserts output thresholds equal the recorded ones |
| 9 | No checkpoint selection / threshold optimisation / tuning on test | no such code path (AST test); only `best` and `last` recorded checkpoints exist; operational FPR flag is a report, not a repair |
| 10 | Results outside historical directories | default `results_final_test/` (new); refusal if the path is inside any `results_phase*` tree or non-empty; results created with mode `"x"` (never overwritten) |
| 11 | Overlap control for both datasets | `overlap_masks`: UNSW — rows whose predictor vector is absent from the official training file; CIC — absent from train/validation; both — unique-within-test and their intersection; computed from raw predictor columns with the Phase 4 `predictor_fingerprint` definition; tested on synthetic UNSW-style and CIC-style frames |
| 12 | Frozen statistical analysis and output schema | `analyze_final_test.py` (mean±SD, per-seed, paired t-CI, exact sign-flip p, FPR shift, overlap tables) tested on synthetic results; schema `final_test_result_v2` described in `FINAL_TEST_SAFE_EXECUTION_PLAN.md` |
| 13 | Resolve version/fingerprint incompatibility transparently | the old gate demanded the Phase 6C code tree *and* repaired metrics, which cannot both hold. New design: **two fingerprints**: (i) *training-code lineage* — each source manifest's fingerprint is re-derived from its frozen git tag tree (`phase6c-final-results` → 1273afef…, `phase7b-final-results` → e93182e4…; both match) and each run is re-verified with `verify_run_dir` against its source manifest; (ii) *evaluation-code fingerprint* (`src/*.py`, `scripts/final_test/*.py`, `p6c_common.py`) frozen in the new manifest. No integrity check is bypassed; both are enforced and tested |
| 14 | Prevent accidental access in ordinary test suites | see `PUBLICATION_BLOCKERS_STATUS.md` / M6: `protected_access_guard.py` (session-wide autouse guard in `tests/conftest.py`, blocks `open`/`io.open`/`os.open` on the three protected files); the three tests that read them were split into default train/validation-only versions and `authorized_integrity` versions, deselected via `pytest.ini` and skipped unless `IOTFL_AUTHORIZED_FINAL_TEST_INTEGRITY=1` |

## Added files
`scripts/final_test/{final_test_v2.py, analyze_final_test.py, protected_access_guard.py}`, `docs/final_test/FINAL_TEST_MANIFEST.json` (frozen; 280 runs = 240 Phase 6C + 40 Phase 7b mandatory), `pytest.ini`, `tests/test_phase9c_final_test_v2.py` (17 tests), modifications of `tests/conftest.py`, `tests/test_phase5_validation.py`, `tests/test_data_integrity_ciciot.py`.
## New capability beyond the old script
`build` / `readiness` / `preproc-equiv` / `authorization-template` / `evaluate --preflight` (all preconditions except the owner's signature) / `evaluate --dry-run` / `evaluate`; authorization additionally requires `plan == final-test-eval-v2` and an acknowledgement that earlier integrity reads were disclosed; probabilities are saved so the analysis can be repeated without re-reading test data.
